# Compilador Costeñol

## Descripción

Compilador e intérprete del lenguaje **Costeñol**, desarrollado en **Python 3**. Permite escribir, analizar y ejecutar programas mediante una interfaz gráfica sencilla.

## Características

* Análisis léxico, sintáctico y semántico.
* Ejecución de programas Costeñol.
* Visualización de tokens, errores y variables.
* Entrada y salida de datos.
* Guardado de archivos `.PQEK`.

## Tecnologías

* Python 
* Tkinter
* re
* threading
* queue

## Funcionalidades

* Variables: `Texto`, `Entero`, `Real` y `Logico`.
* Captura de datos.
* Operaciones aritméticas.
* Mensajes en pantalla.
* Comentarios con `//`.


## Objetivo

Proyecto académico desarrollado para comprender las etapas de un compilador: análisis léxico, sintáctico, semántico y ejecución.
